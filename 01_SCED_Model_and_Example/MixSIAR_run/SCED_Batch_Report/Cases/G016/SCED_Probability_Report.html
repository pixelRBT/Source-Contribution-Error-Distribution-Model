How to read this: A source with a 90% AE value of 20 pp has a model-predicted 90% probability that its absolute contribution error does not exceed 20 percentage points; it is not a guaranteed error bound. P(AE > 0.20 ) is the predicted probability that the true contribution differs from the MixSIAR posterior mean by more than 20.0 pp .

Applicability and limitations

  • The model was developed with 6 mixture observations; this case has 2.
  • Source sample sizes differ from nominal n = 6 used in the simulations.
  • Zero isotope discrimination is assumed for this case; the discrimination file is not read or checked.
  • SCED was evaluated on simulated water mixtures; actual source errors are unknown in this case.
